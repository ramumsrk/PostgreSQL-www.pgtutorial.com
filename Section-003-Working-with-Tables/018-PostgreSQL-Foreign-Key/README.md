# PostgreSQL Foreign Key

## Introduction to foreign keys

A _foreign_ _key_ is a column or set of columns that references a _primary_ _key_ in another table

Table containing the _primary_ _key_ is called _parent_ or _referenced_ table

Table containing the _foreign_ _key_ is called _child_ or _referencing_ table
